Budgets

Hard ceilings.
Zero surprises.

Cap what a loop is allowed to spend before it spends it — tokens, dollars, time, or iterations. Any dimension left unset is simply not enforced.

Tokens
maxTotalTokens
Cumulative input + output tokens across every recorded step.
Cost
maxTotalCostUsd
Estimated USD via an overridable pricing table. Fails loud, not silent, if cost can't be resolved.
Wall-clock
maxWallClockMs
Enforced by an internal timer — trips even with zero recordStep() calls.
Iterations
maxIterations
A hard cap on the number of recordStep() calls, independent of content.

Detection

Catches stuck loops.
For free.

Two zero-cost heuristics — no embeddings, no extra API calls — spot the two most common ways an agentic loop wastes your budget.

🎯
Convergence
Is this one state stuck? Several consecutive near-identical outputs — or an explicit isFinal signal from the loop — halt with reason "converged".
🔁
Drift
Is this oscillating between ≥2 states? Averaged similarity across a repeating cycle (with a per-pair floor) catches A→B→A→B loops, halting with reason "drift".

API

Small surface.
Composable core.

createLoopGuard(config?): LoopGuardInstance
The single entry point. Every field on config is optional.
guard.signal: AbortSignal
Thread into corellm's signal on every LLM call — aborts an in-flight call the instant the guard trips.
guard.recordStep(step): HaltVerdict
Record one iteration's content/usage. Updates counters and evaluates every trip condition immediately.
guard.shouldHalt(): boolean
Check at the top of your loop. Re-checks wall-clock even with no new steps.
guard.snapshot(): GuardSnapshot
Point-in-time counters: iterations, tokens, cost, elapsed time, trip state.
guard.reset(): void
Clears all counters and re-arms a fresh, non-aborted signal.
pricing?: PricingTable
Overrides DEFAULT_PRICING (illustrative $/1M-token rates) for cost budgets.
onHalt?: (verdict) => void
Fires exactly once, the first time the guard trips, for any reason.
